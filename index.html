Integrasi Google Sheets & Web App

Konfigurasikan integrasi pengiriman data hasil survei langsung ke instansi Google Spreadsheet Anda.

1

Buat Google Spreadsheet Baru

Buat dokumen Spreadsheet di Google Drive Anda. Di tab pertama, biarkan dalam keadaan kosong. Baris judul kolom (Header) otomatis terbuat saat respon pertama masuk.

2

Salin & Tempel Google Apps Script

Di Google Spreadsheet, buka menu Ekstensi > Apps Script. Hapus semua kode default, lalu salin dan tempel kode lengkap di bawah ini:

Google Apps Script (code.gs) 
function doGet(e) {
  try {
    // Endpoint GET untuk mengekstrak seluruh data lembar kerja untuk di-ekspor ke Excel
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = sheet.getDataRange().getValues();
    return ContentService.createTextOutput(JSON.stringify({ "status": "success", "data": data }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (error) {
    return ContentService.createTextOutput(JSON.stringify({ "status": "error", "message": error.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

function doPost(e) {
  try {
    // Membuka spreadsheet aktif
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    
    // Jika sheet kosong, buat header baris pertama secara otomatis (Menampung pemisahan Nama & Instansi)
    if (sheet.getLastRow() === 0) {
      sheet.appendRow([
        "Timestamp", 
        "Nama Responden",
        "Kategori Responden", 
        "P1: Respon Layanan LPSE", 
        "P2: Kecepatan Layanan", 
        "P3: Pemahaman Personel", 
        "P4: Kesesuaian Tindakan", 
        "P5: Kejelasan Informasi", 
        "P6: Kesesuaian Prosedur", 
        "Saran & Masukan"
      ]);
      
      // Memberikan efek format pada Header agar lebih rapi
      var range = sheet.getRange(1, 1, 1, 10);
      range.setFontWeight("bold");
      range.setBackground("#991b1b"); // Warna merah gelap khas LPSE
      range.setFontColor("#ffffff");
      range.setHorizontalAlignment("center");
      sheet.setFrozenRows(1);
    }
    
    // Parsing data kiriman dari Web Form
    var data = JSON.parse(e.postData.contents);
    
    // Menulis baris respon baru
    sheet.appendRow([
      data.timestamp || new Date().toISOString(),
      data.nama,
      data.kategori,
      parseInt(data.q1),
      parseInt(data.q2),
      parseInt(data.q3),
      parseInt(data.q4),
      parseInt(data.q5),
      parseInt(data.q6),
      data.saran
    ]);
    
    // Otomatis menyesuaikan lebar kolom
    for (var i = 1; i <= 10; i++) {
      sheet.autoResizeColumn(i);
    }
    
    // Respon sukses
    return ContentService.createTextOutput(JSON.stringify({ "status": "success", "message": "Respon berhasil disimpan." }))
      .setMimeType(ContentService.MimeType.JSON);
      
  } catch (error) {
    // Respon error jika terjadi kesalahan teknis
    return ContentService.createTextOutput(JSON.stringify({ "status": "error", "message": error.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
3

Deploy / Terapkan sebagai Web App

1. Klik tombol Terapkan (Deploy) di kanan atas Apps Script > Pilih Penerapan baru (New deployment).
2. Pilih jenis penerapan: Aplikasi web (Web app).
3. Pada kolom "Jalankan sebagai" pilih: Saya (Email Anda).
4. Pada kolom "Siapa yang memiliki akses" pilih: Siapa saja (Anyone).
5. Klik Terapkan, selesaikan Otorisasi Akses Google, dan salin URL Aplikasi Web yang dihasilkan.

4
